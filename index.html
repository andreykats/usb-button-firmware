Key

Change the key

  1. Press BOOT and let go.
  2. The button switches to the next key and types it, so you can see which key it is now. Keys go a to z, then 0 to 9.

Let go within 3 seconds: holding BOOT longer restarts the button for this page instead.

Connect

  1. Plug the button into this computer.
  2. Hold BOOT for 3 seconds. The button restarts and its light cycles through all colours.
  3. Click Connect and choose USB Button. It’s listed with the button’s key and ID, e.g. “USB Button [2] (EB:F4:58)”.

Browser not supported

This page talks to the button over Web Serial. Use Chrome, Edge, Opera or Firefox (151 or later) on a computer; Safari doesn’t support it.
